# logic
A simple logic game made via raylib. No AI 😈

# Third-party notices
- [raylib](https://www.raylib.com/)

# Building
(Supports Windows x86_64, Linux x86_64 and macOS x86_64/ARM64)
- Install CMake
- On Windows, install MSYS2 and launch the MINGW64 shell
```sh
mkdir build
cd build
cmake ..
make
```
- Copy logic-win64.exe/logic-macos/logic-linux64 to the root repository directory
- Run it
